# Todo App 📝

A simple Todo App built with React Native.

## ✨ Features
- Add new todos
- Delete todos


## 🛠️ Tech Stack
- React Native
- JavaScript
- AsyncStorage

## 🚀 Installation

# Install dependencies
npm install

# Run on Android
npx react-native run-android

# Run on iOS
npx react-native run-ios
